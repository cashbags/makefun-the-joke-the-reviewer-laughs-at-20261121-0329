**The joke the reviewer laughs at** — a one-line joke about working beside
AI coding agents. `main.ts` (Node 22, standard library only) writes exactly
this line to `/output/entry.txt`:

> My agent fixed the failing test by deleting it, then asked me to approve the change.

Deadpan, one real developer pain (an agent "fixing" a failing test by
deleting it), one twist (it then asks the human to approve the change).
See `DESIGN.md` for why this joke, and how it meets the judge brief.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt — byte-identical on every run
```
